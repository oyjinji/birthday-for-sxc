# SXC大王23岁生日快乐

可直接部署的竖屏静态生日网页，无需依赖、构建或后端。

## 背景声音（v4）

- 海浪更换为塞舌尔沙滩的小浪拍岸录音，与上一版使用不同素材。
- 叠加低音量、无人声的音乐盒版生日旋律，留出短暂间奏，海浪始终保留。
- 海浪与旋律预混为同一段内嵌 PCM 音频，沿用 v3 的本地播放和原生音频回退；右上角声音按钮统一控制背景音与烟花。
- 原有五发成组烟花、画面同步及混音限幅保留。

## 声音兼容

- 声音已转换为通用 PCM WAV，随 `assets/audio-data.js` 内嵌，不再通过 `fetch` 读取 MP3，避开本地文件读取和资源请求失败。
- Web Audio 无法启动时自动切换原生音频播放；微信/iOS 返回前台后可通过再次触摸激活声音。
- 烟花每组五发，在 0.3 秒内错开绽放，每一发爆响跟着对应画面触发；兼容模式使用五发预混音，避免手机限制同时打开多个音频播放器。
- 增加混音限幅，避免多发叠加时出现过大的尖锐音量；关闭声音、重播或切换后台会停止正在播放的烟花。

1. 「闭上眼睛，许个愿吧」移到海平线下方的海面区域。
2. 删除长按按钮的进度读条，只保留按下缩小、颜色和轻微阴影反馈。

4. 愿望揭晓时整根蜡烛淡出；重播回到许愿时，重新显示点亮的蜡烛。
5. 最终标题分为「SXC大王」「23岁生日快乐」两行，副文案为「愿你的每一个愿望，都慢慢绽放。」
6. 背景使用新海浪与轻柔生日旋律，烟花绽放时成组播放对应的烟花声音。

## 文件与上传

ZIP 解压后，把里面的全部文件上传到静态站点根目录；确保 `index.html` 位于根目录，`assets/` 保持相对位置。Cloudflare Pages 不需要构建命令。

- `index.html`：三幕画面、生日文案。
- `styles.css`：布局、配色、按下反馈与动画。
- `app.js`：镜头、许愿、角色跳舞、烟花与手机视差。
- `audio.js`：内嵌音频解码、原生播放回退、混音和同步。
- `assets/audio-data.js`：内嵌 PCM 音频数据，必须一并上传。
- `assets/`：透明角色、海浪与烟花音效、图标及素材说明。

页面使用本地资源，不依赖外部字体、素材网站或第三方脚本。部署后播放音效不会访问 Freesound。素材来源见 [assets/CREDITS.md](assets/CREDITS.md)。

更新部署时请同时上传所有文件；HTML 已给脚本与样式增加版本参数，帮助浏览器刷新旧缓存。

## 操作与预览

轻触开场进入蛋糕近景。按住「长按许愿」至少约 0.65 秒，闭眼许愿；想好后松开，无需等任何读条。镜头随后拉远、烟花绽放，两个角色围着野餐垫跳舞。点击「再许一次愿」可返回许愿。

声音默认关闭；点右上角声音按钮后，新海浪与轻柔生日旋律一起循环播放，烟花爆响跟随画面绽放。切换后台会取消未完成的长按、暂停动画与声音。系统开启「减少动态效果」时，减少晃动和连续运动，并保留祝福流程。

完整解压后可直接双击 HTML 预览，音频不再依赖 HTTP 请求。也可在此目录运行 `python -m http.server 8765` 后打开 `http://localhost:8765/`。部署时请上传整个目录，尤其不要遗漏 `assets/audio-data.js`；替换旧版本后刷新页面。

「轻晃」按钮用于开启手机倾斜视差，部分手机需要方向传感器授权。此功能需要 HTTPS 和浏览器支持；浏览器不开放传感器时仍可完成全部触摸交互，电脑上也可用鼠标体验视差。无需微信 JS SDK 或公众号签名。

已在浏览器中检查 Web Audio 与原生音频播放、多发混音和完整许愿流程；另外模拟本地文件来源并禁用网络读取完成了回归检查。微信的实际授权与传感器表现仍需部署后在真实手机上确认。
